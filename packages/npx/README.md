# TraceDojo

A booking succeeds. Its confirmation times out. Your agent retries—and books twice.

TraceDojo reproduces that failure, shows what actually changed, and checks the fix.

```sh
npx tracedojo demo
npx tracedojo init
npx tracedojo test
```

Use Node.js 22.23.1 or later. The demo is scripted and requires no model key.
It saves failed and fixed reports for inspection in the TraceDojo Workflows page.

This package is the Apache-2.0 command-line launcher for
[@tracedojo/sdk](https://www.npmjs.com/package/@tracedojo/sdk).
